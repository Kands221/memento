# Memento: 3-minute demo script

## Before you go on stage

- [ ] iPhone 15 Pro or newer on iOS 26. **Settings → Apple Intelligence & Siri** is on, and the model has finished downloading.
- [ ] Memento installed from Xcode. In the app, **You → On-device AI** says **READY · WORKS OFFLINE**.
- [ ] **You → Demo → Load sample journal** is done, so the journal shows a 3-day streak and Revisit.
- [ ] Low Power Mode is **off** (it slows the model), Reduce Motion is **off**, and Do Not Disturb is **on**.
- [ ] Battery is above 50%, and screen mirroring has been tested.
- [ ] Warm up the model once: write "test", save, wait for suggestions, then delete that entry or leave it.

## The flow

1. **Onboarding, 30 s.** Go to **You → Replay welcome**.
   - Say: *"Memento is a journal that helps you notice."*
   - Tap **See how it works → Find the details**. Point out the dashed suggestions, each tied to the words behind it.
   - Tap **Keep** on *Walking helped*, then Continue: *"…and find that part of your life again."*
   - On the last step: *"Private by design. Tagging runs on this iPhone."*
2. **Write, 45 s.** Tap **＋ → Write freely → Use example → Save**.
   - Say: *"Saving is instant. It never waits for AI."*
   - "Finding details on this iPhone…" appears, then the live suggestions: a feeling, a situation, what helped, a topic.
   - Tap one to show its highlighted words, then tap **Keep**.
3. **Find again, 30 s.** Tap a kept chip, for example *Walking helped*. The tag detail shows the timeline, every moment it appears, and what else was kept alongside it.
   - Tap **Summarize these entries → For my psychologist or psychiatrist → Preview summary**.
   - Say: *"Counts of what I wrote, not a diagnosis."*
4. **Sol, 45 s.** Go to **You → Reflect with Sol**. Type: *"Work has been a lot and I keep saying yes to everything."*
   - Watch Sol's pose change while it thinks, then the reply streams in.
   - Tap a quick reply, then **Turn this into a reflection → Save to journal**.
5. **Offline proof, 15 s.** Turn on **airplane mode**. Write another entry and save it. Suggestions still arrive.
6. **Graceful states, 15 s.** Go to **You → Demo → AI state → Unsupported**, then show **On-device AI** and Sol's resting screen.
   - Say: *"No cloud fallback, and everything still works by hand."*
   - Set the AI state back to **Live**.

## If something goes wrong on stage

| Problem | Fix |
|---|---|
| Suggestions are slow or don't arrive | Go to **You → Demo → Suggestion engine → Built-in rules (backup)**. It's instant and deterministic. |
| Sol is slow or odd | Go to **You → Demo → Sol engine → Scripted (backup)**. |
| "Turn on Apple Intelligence" shows | Use the backup engines above. They work on any device. |
| Need a clean slate | Go to **You → Demo → Clear journal**, then **Load sample journal**. |
